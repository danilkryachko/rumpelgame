# Cave Generation Foundation

This document records the first deterministic cave metadata layer for world generation. The current layer samples a cave mask from explicit world generator inputs and block coordinates, but it does not alter chunk bytes, block IDs, atlas assets, storage, protocol, renderer behavior, or default generation.

## Current Contract

- `cave_v1` is owned by `server/pkg/world/cave.go`.
- Inputs are `GeneratorConfig.Seed`, `GeneratorConfig.DimensionID`, world block `X/Y/Z`, and `CaveAlgorithmVersionV1`.
- `WorldGenerator.SampleCave()` and `DeterministicCaveID()` return deterministic metadata for `solid` or `open`.
- `CaveDefinitionsV1()` exposes stable cave mask IDs and display names.
- The sampler treats coordinates outside the supported cave Y band as `solid`.
- `TestCaveSamplerDoesNotChangeGeneratedChunkBytes` proves sampling leaves `flat_v1` chunk bytes unchanged.
- `scripts/cave_sampler_matrix_gate.sh` records the representative matrix hash `f265ead2a700736c1e9b13056004af9c5c242d083c74c56d48e2cc76d1dfeeee`.

## Rollout Boundary

The metadata layer exists so cave masks can be tested before a versioned generator carves blocks, changes serialized chunk entropy, refreshes storage/RLE/streaming evidence, and proves visual/collision behavior.

Cave metadata must not become chunk content until a separate generator version applies the mask to approved block IDs and refreshes downstream evidence.

## Blocked Changes

- Carving caves into generated chunks without a new generator version.
- Changing `Chunk.Serialize()` or `ChunkData.blocks`.
- Changing default `flat_v1` generated bytes.
- Persisting cave metadata outside serialized chunk bytes without a storage design.
- Inferring hidden cave state on the client from partial chunk data.

## Gate

Use:

```sh
sh scripts/cave_sampler_matrix_gate.sh logs/cave_sampler_matrix_current
```

Expected current result:

- `status=pass`
- `matrix_status=guarded`
- `metadata_runtime=matrix_only`
- `algorithm_version=cave_v1`
- `samples=12`
- `solid=8`
- `open=4`
- `sample_hash=f265ead2a700736c1e9b13056004af9c5c242d083c74c56d48e2cc76d1dfeeee`
- `active_worldgen_change=0`
- `active_serialization_change=0`
- `protocol_change=0`
- `world_tests=pass`

## Current Status

This layer is complete as a deterministic metadata foundation. Cave sampling is guarded and reproducible. The separate opt-in `cave_height_v1` generator applies this mask to chunk block content with downstream serialization evidence, while default `flat_v1` generation remains unchanged.
